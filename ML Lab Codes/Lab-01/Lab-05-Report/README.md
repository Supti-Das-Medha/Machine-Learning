# Lab 01: Data Preprocessing and Regression Model Evaluation

## Overview
This lab focuses on understanding the basic steps of a machine learning workflow.
It covers data preprocessing, splitting the dataset into training and testing sets, 
implementing regression models, and evaluating their performance using different evaluation metrics.

## Objectives
- To understand the importance of data preprocessing.
- To prepare a dataset for machine learning.
- To divide the dataset into training and testing sets.
- To implement regression models.
- To evaluate model performance using MAE, MSE, RMSE, and R² Score.

## Topics Covered
1. Data Preprocessing
2. Train-Test Split
3. Regression Model Implementation
4. Model Evaluation
5. Performance Analysis

## Evaluation Metrics
The following metrics are used to evaluate the regression models:

- **MAE (Mean Absolute Error):** Measures the average absolute difference between actual and predicted values.
- **MSE (Mean Squared Error):** Measures the average squared difference between actual and predicted values.
- **RMSE (Root Mean Squared Error):** Represents the square root of the mean squared error.
- **R² Score:** Indicates how well the model explains the variation in the target variable.
