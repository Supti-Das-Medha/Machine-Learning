# Lab 03: Introduction to Support Vector Machines (SVMs)

## Overview
This lab focuses on understanding Support Vector Machines (SVM), a supervised machine learning algorithm used for classification and regression tasks. It introduces the basic concepts of SVM and explores how it works to find the optimal decision boundary for separating data points.

## Objectives
- To understand the basic concept of Support Vector Machines.
- To learn how SVM works in machine learning.
- To understand the concept of hyperplanes and support vectors.
- To implement an SVM model using Python.
- To evaluate the model's performance.

## Topics Covered
1. Introduction to Support Vector Machines.
2. Understanding Hyperplanes and Support Vectors.
3. SVM Model Implementation.
4. Model Training and Testing.
5. Performance Evaluation.
