# Lab 04: Introduction to K-Means and Agglomerative Algorithm

## Overview
This lab focuses on understanding two popular unsupervised machine learning algorithms: K-Means Clustering and Agglomerative Clustering. It explores how these algorithms group similar data points into clusters without using predefined labels.

## Objectives
- To understand the basic concepts of clustering.
- To learn how the K-Means algorithm works.
- To understand Agglomerative Clustering.
- To implement both clustering algorithms using Python.
- To analyze and compare the clustering results.

## Topics Covered
1. Introduction to Unsupervised Learning.
2. Basics of Clustering.
3. K-Means Clustering Algorithm.
4. Agglomerative Clustering Algorithm.
5. Model Implementation and Result Analysis.

## Tools and Technologies
- Python
- Jupyter Notebook / Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Learning Outcome
Through this lab, I learned how clustering algorithms work and how to group similar data points using K-Means and Agglomerative Clustering. I also gained practical experience in implementing these algorithms and analyzing their results.
