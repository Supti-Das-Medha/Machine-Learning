# Lab 05: Introduction to Pipeline, Cross-Validation & Statistical Testing

## Overview
This lab focuses on understanding machine learning pipelines, cross-validation techniques, and statistical testing. It explores how pipelines help organize machine learning workflows, how cross-validation evaluates model performance, and how statistical tests help compare different models.

## Objectives
- To understand the concept of machine learning pipelines.
- To learn how to create and use pipelines.
- To understand the importance of cross-validation.
- To implement cross-validation techniques.
- To learn the basics of statistical testing.
- To compare model performance using statistical methods.

## Topics Covered
1. Introduction to Machine Learning Pipelines.
2. Pipeline Implementation.
3. Introduction to Cross-Validation.
4. Cross-Validation Implementation.
5. Introduction to Statistical Testing.
6. Model Comparison and Performance Analysis.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- SciPy

## Learning Outcome
Through this lab, I learned how to organize machine learning workflows using pipelines, evaluate model performance through cross-validation, and apply statistical testing to compare models. This lab also helped me understand the importance of reliable model evaluation and comparison.
