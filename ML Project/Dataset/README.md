# Dataset

This folder contains the dataset used in the Machine Learning project.

The dataset includes agricultural soil and environmental features such as Nitrogen (N), Phosphorus (P), Potassium (K), Temperature, Humidity, pH, and Rainfall.

The dataset is used to evaluate crop recommendation models.

### Dataset Limitation

One limitation of the dataset is that it does not distinguish between seasonal and non-seasonal (perennial) crops. In real-world agriculture, some crops, such as rice, wheat, and mustard, are seasonal, while others, such as pomegranate, coconut, and mango, are perennial crops that can be cultivated across different seasons or throughout the year.

However, the current dataset does not consider this distinction. As a result, the model may recommend crops without considering their actual cultivation patterns and seasonal characteristics. Including crop types and their growing-season information could make the recommendation system more realistic and suitable for practical agricultural use.
